Halaman ini terbuka di dalam aplikasi lain (mis. WhatsApp). Ketuk menu ⋮ / ikon kompas lalu pilih “Buka di Chrome” (Android) atau “Buka di Safari” (iPhone), atau salin link di bawah.

Buka aplikasi
Android · Google Chrome
  1. Buka halaman ini di Google Chrome.
  2. Ketuk tombol Pasang aplikasi di atas — atau menu ⋮ di kanan atas.
  3. Pilih Instal aplikasi / Tambahkan ke layar utama, lalu Instal.
  4. Ikon FirstAid SASU3B muncul di layar utama & laci aplikasi.
iPhone / iPad · Safari
  1. Buka halaman ini di Safari (bukan Chrome atau WhatsApp).
  2. Ketuk tombol Bagikan di bilah bawah.
  3. Gulir, pilih Tambahkan ke Layar Utama.
  4. Ketuk Tambah — ikon FirstAid SASU3B muncul di layar utama.
Windows / Mac · Chrome atau Edge
  1. Buka halaman ini di Chrome atau Edge.
  2. Klik tombol Pasang aplikasi di atas, atau ikon pasang di ujung kanan bilah alamat.
  3. Klik Instal — aplikasi terbuka di jendela sendiri dan ada di menu Start / Launchpad.
